# É Pra Você — site público

Experiência original de acolhimento e mensagens em português brasileiro, com Lumi. Nome interno preservado: MENSAGENS_FOFAS_OS.

Site oficial: https://idelta775-hash.github.io/e-pra-voce-mensagens/

## Funcionalidades

- Três mensagens na capa, de bom dia, boa tarde e boa noite.
- **Uma mensagem para este momento**: 36 textos originais, 18 combinações entre tema e horário, até duas versões para cada escolha.
- Compartilhamento nativo, sem login, rastreadores, anúncios ou notificação push.
- Experiência sem rolagem infinita ou engajamento compulsivo.
- Compatível com celular e recursos básicos de acessibilidade.

Arquivos fonte: index.html, style.css, app.js e momentos.js. Teste interativo: test_momento.py.

O projeto ainda não tem links sociais públicos verificados nem monetização ativada. Nenhuma senha, cookie ou informação de visitantes foi incluída neste repositório.
